# My Rhythm

My Rhythm — проект о том, как выбирать еду, отдых и повседневные привычки с учётом самочувствия и планов на день. Пока первая версия готовится к запуску, на сайте можно попробовать интерактивный пример и записаться в ранний доступ.

## Что можно попробовать

Представь, что после работы ты заходишь в магазин. Дома есть готовая гречка, а на ужин — десять минут. Первый совет — купить яйца и помидоры и приготовить их с гречкой на сковороде. Кнопка «Сегодня без готовки» предлагает другой вариант и меняет список покупок на готовую курицу с овощами. Если сохранить ужин, он останется отмеченным до перезагрузки страницы.

В форме раннего доступа достаточно оставить электронную почту. Сервер сохраняет адрес в SQLite и объединяет повторные заявки с одного адреса. При ошибке сети адрес остаётся в поле, чтобы можно было отправить заявку ещё раз.

## Локальный запуск

Интерфейс написан на React и собирается с помощью Vite. Для сервера нужен Node.js со встроенным модулем `node:sqlite`. Проект проверен на Node.js 26.

```sh
npm ci
npm run dev
```

Открой локальный адрес, который Vite выведет в терминал.

Для запуска собранного приложения с обработчиком заявок выполни обе команды из корня проекта.

```sh
npm run build
npm start
```

По умолчанию сервер доступен по адресу [localhost:4173](http://localhost:4173). При первой заявке он создаст базу `.data/early-access.sqlite`. Порт можно задать переменной окружения `PORT`, а каталог базы — `RHYTHM_DATA_DIR`.

## Регрессионные тесты

После клонирования выполни из корня проекта на Node.js 26:

```sh
npm ci
npx playwright install --with-deps --only-shell chromium
npm test
```

`npm test` собирает приложение, запускает локальный сервер на свободном порту и использует отдельную базу SQLite в `test-results/data/`. Тесты сверяют валидацию email через форму и API и проверяют переход с клавиатуры по ссылке «Посмотреть пример» на ширинах 360, 768 и 1440 px.

Тексты страницы, сценарии демо и критерии приёмки собраны в [спецификации проекта](docs/SPEC.md).
